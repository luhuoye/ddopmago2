# ꅇꂷꇬ (com.ddopmago)
彝文(规范彝文/凉山) ⇄ 普通话 词句库检索 + 内置彝文键盘 + 收藏 + 做题。

## 打包 APK（GitHub）
1. 新建 **私有** 仓库，把本目录全部文件(含隐藏的 .github)推送到 main 分支。所有数据（词库、2008词典分卷 `assets/dict/dict.zip.00/01`、字体、古彝文词典、书籍、试卷）都已内置，构建过程不需要联网下载任何内容。
2. Actions → Build APK 自动运行，下载 Artifacts 里的 `ddopmago-apk`。
3. 安装后第一次打开，软件把词典分卷合并解压到应用目录。

## 功能
- 输入：全部文字输入都用内置键盘（不弹系统键盘）。⇄ 键切换：彝文(拼音候选+字表) / 中文拼音(ü用v) / 字母(可大写) / 符号·数字·数学符号；字典和翻译页有「粘贴」键（做题、考试、试卷作答时没有粘贴和复制）。
- 翻译：彝⇄中 词句检索（例句+词典词条），可收藏、复制。
- 字典：词句分类、彝汉词典(《规范彝文词典》例词)、词库(5.7万词)、音节表、部首检字(26个部首×笔画)、2008词典(mdx/mdd，带发音)、古彝文词典(4120个古彝字：释义/读音检索、部首检索、方言读音)、字体(10种现代彝文字体可更换；古彝文字体固定内置)。
- 做题：练习(选择/判断/填空/翻译/拼音/书籍题/收藏题)、模拟考试(满分100)、错题本(相似题推荐)、共享(.ddop 试卷分享/导入)、打印(试卷、成绩、资料 → PNG)。
- 学习：试卷(可在线答题判分)、资料、书籍(带目录：勒俄特依、阿莫里惹、玛牧特依、凉山民间故事选)，长按一行可复制或收藏词句。
- 收藏：词句、题目、摘录、记录。
- 所有现代彝文逐字标拼音（拼音题题干除外）；古彝文用内置古彝文字体显示。

## 说明
- 翻译为《彝语900句》942 个句子的相似度检索，不是机器翻译；词库外的内容查不到。
- 彝文显示依赖系统自带 Noto Sans Yi 字体，个别国产 ROM 如显示方块，需自行加入字体文件。
- 词库来自《彝语900句》(版权属原出版社/作者)，仓库请保持私有，公开发布前需取得授权。
- 试卷/资料数据：`python3 tools/build_papers.py <中考资料目录> <高考加试目录>`。
- 重新生成数据：先 `python3 tools/build_corpus.py book.md`，再 `python3 tools/build_dict.py 词库.txt dictraw.txt app/src/main/assets/sentences.json`。
- 彝学研究网在线词典(yixueyanjiu.com)禁止自动抓取，未导入。
- 古彝文数据：tools/build_ancient.py（来源 yidir《通用彝文字典》数据集）；书籍与题库：tools/build_books.py、tools/build_bookqs.py；中文拼音表 pinyin.json 由 Unicode 拼音排序数据整理。
- 方正彝文字体、Microsoft Yi Baiti、SIL Yi、LSTY 古彝文字体均为你提供的文件，请遵守各自许可，仓库保持私有。
